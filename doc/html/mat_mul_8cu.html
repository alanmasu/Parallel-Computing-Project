Detailed Description

Implementation of matrix multiplication using CUDA and cuBLAS.

Author
Alan Masutti (@alanmasu on GitHub)

This file contains the implementation of matrix multiplication using CUDA Cores and Tensor Cores. It includes functions for serial matrix multiplication, cuBLAS matrix multiplication, and Tensor Core matrix multiplication. The code also includes error handling for CUDA and cuBLAS operations.
