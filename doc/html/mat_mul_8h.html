Detailed Description

Header file for matrix multiplication functions.

Author
Alan Masutti (@alamasu on GitHub)

This file contains the declarations of functions for performing matrix multiplication using CUDA and cuBLAS. It includes functions for serial matrix multiplication, cuBLAS matrix multiplication, and tensor core matrix multiplication. It also includes utility functions for print and converting matrices between different formats.
